## Download: [Here](https://modrinth.com/datapack/better-death-by-widder)

With this datapack/mod, after death your items will be dropped on the ground in a bundled form.

If you find any bugs or have any Datapack/Mod suggestions, please let me know on my [Discord](https://discord.gg/fy4KuxYKVD).

![GIF](https://cdn.modrinth.com/data/cached_images/0644276474778ce0497d44c669da0e581eea0e1d.gif)

## Mods
- If you use Fabric you must have a version of [Fabric API](https://modrinth.com/mod/fabric-api) also installed
- If you use Quilt you must have a version of [Quilted Fabric API](https://modrinth.com/mod/qsl) also installed
